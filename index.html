Calibrar

Conectá primero para desbloquear este paso.

Origen del lienzo. Poné el cabezal donde querés el CENTRO del dibujo y marcá el origen. Todo se mide desde ahí. Mantené apretadas las flechas para moverte rápido.

Movés cada eje con las flechas (mantené apretado = continuo). El lienzo es un rectángulo de ± pulsos desde el centro; fuera de eso no se mueve.

Eje X

X = 0

Eje Y

Y = 0

Proporción de ejes

Los ejes avanzan distinto por pulso. Medí cuántos pulsos tarda cada eje en cruzar el MISMO tramo del papel, y guardá. Sirve para que el cuadrado salga cuadrado.

Pulsos contados — X: 0 Y: 0

Tamaño del lienzo

Cuántos pulsos a cada lado del centro. Fuera de este rectángulo el cabezal no se mueve. Usá "Fijar aquí" en un borde para tomarlo de la posición actual.
